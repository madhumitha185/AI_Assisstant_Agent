# CS301 — Data Structures & Algorithms (Syllabus Excerpt)

## Course Unit 3: Trees and Graphs

### Learning Objectives
By the end of this unit, students should be able to:
- Define and differentiate between binary trees, binary search trees (BST), and AVL trees.
- Implement tree traversal algorithms: in-order, pre-order, post-order, and level-order.
- Explain the concept of tree balancing and why AVL trees guarantee O(log n) operations.
- Represent graphs using adjacency lists and adjacency matrices.
- Implement Breadth-First Search (BFS) and Depth-First Search (DFS) on graphs.
- Analyze time and space complexity of tree and graph algorithms.

### Topics Covered
1. Binary Trees: structure, properties, and array vs. linked representation.
2. Binary Search Trees: insertion, deletion, search, and complexity analysis.
3. AVL Trees: rotations (LL, RR, LR, RL) and self-balancing.
4. Graph Representations: adjacency list vs adjacency matrix, trade-offs.
5. Graph Traversal: BFS using a queue, DFS using recursion/stack.
6. Applications: shortest path in unweighted graphs via BFS, cycle detection.

### Assessment
- Quiz 3 (Trees & Graphs): 10 MCQs, covers traversal orders and complexity.
- Assignment 3: Implement an AVL tree with insertion and rotation logic in Python.

### Recommended Reading
- Cormen, Leiserson, Rivest, Stein — "Introduction to Algorithms," Chapters 12–13 and 22.
